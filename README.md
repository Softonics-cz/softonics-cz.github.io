# Softonics GitHub Pages website

Deployment files for https://softonics-cz.github.io/.

The website source is maintained in https://github.com/Softonics-cz/public-web.
This deployment is based on commit `2de52778ec6952e46eecb52e162878bde768509e`.

These static files are ready to publish from the root of the publishing branch.
In Settings → Pages, use **Deploy from a branch** and the branch root (`/`).
No build step or external dependencies are required. `.nojekyll` bypasses Jekyll processing.

The contact links open the visitor’s email application. Manrope’s font license is in `assets/OFL.txt`.
